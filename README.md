# 🎯 Projeto Raio-X da Juventude

> Análise de Condições de Vida e Métricas para Atuação Social e Educacional.

## 📌 Visão Geral
O **Raio-X da Juventude** é um projeto de análise de dados voltado ao diagnóstico das condições socioeconômicas, educacionais e de qualidade de vida dos jovens. O objetivo principal é transformar dados brutos em indicadores acionáveis para embasar políticas públicas e iniciativas educacionais.

---

## 🛠️ Tecnologias e Bibliotecas
- **Linguagem:** Python 3.x (Google Colab)
- **Análise de Dados:** `pandas`, `numpy`
- **Visualização:** `plotly`, `chart.js`
- **Web & Interface:** HTML5, Tailwind CSS
- **Hospedagem:** GitHub Pages
